#define TEMP_SENSOR_BED     3000

3. Contador e condicionais

Sempre usar MULTI_BED_COUNT em arrays e loops (for (uint8_t b = 0; b < MULTI_BED_COUNT; b++)).

HAS_HEATED_BED → habilita cama única.

ENABLED(ENABLE_MULTI_HEATED_BEDS) → ativa I²C, ADS1115, PCF8574 e múltiplas camas.

4. Enums e índices

enum ADCSensorState → StartSampling, PrepareTemp_BED0…PrepareTemp_BED3, MeasureTemp_BED0…MeasureTemp_BED3, SensorsReady, StartupDelay.

typedef enum : int8_t heater_id_t → inclui H_BED0…H_BED3, H_BED=H_BED0 (legado), demais H_E0…H_E7, etc.

enum IdleIndex { IDLE_INDEX_BED0… } + idle_index_for_id().

enum RunawayIndex { RUNAWAY_IND_BED0… } + runaway_index_for_id().

5. Estruturas centrais

6. Fluxo original x multi‑bed

ISR em Temperature::isr() → substituir PrepareTemp_BEDx / MeasureTemp_BEDx por leitura ADS1115.

readings_ready() / update_raw_temperatures() → acumula e sinaliza prontidão.

analog_to_raw_bed(celsius) → converte °C→raw via termistor/tabela.

analog_to_celsius_bed(raw, idx) → converte raw→°C.

manage_heated_bed(bed, ms) → lógica bang–bang (sem PID para camas).

Single-bed: _PWM_MOD / _SLOW_PWM

Multi-bed: update_bed_pwm_pcf8574()

6. **Fluxo original × multi-bed**  
- **Single-bed**: ISR usava `PrepareTemp_BED` / `MeasureTemp_BED` + `ACCUMULATE_ADC()`.  
- **Multi-bed**:  
  1. **No ISR** `Temperature::isr()` não há mais cases de cama — todo o ADC de camas é lido pelo ADS1115.  
  2. **Dentro de** `readings_ready()` (no bloco de StartSampling/SensorsReady), chamar:  
     ```cpp
     readings_ready();                  // atualiza hotends, chamber, cooler…
     read_bed_temperatures_ads1115();   // sua rotina ADS: raw16→raw10→setraw()/celsius
     ```  
  3. O ADS1115 faz internamente start+wait+read por canal.  
  4. O controle PWM continua via loops sobre `soft_pwm_bed[b]` e `bedPCF.write(mask, on)` em `update_bed_pwm_pcf8574()`.
